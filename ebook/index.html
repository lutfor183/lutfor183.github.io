Because the site does not send Access-Control-Allow-Origin, the browser needs a CORS proxy. Troubleshooting & error meanings (Aug 2026 update)
  • You opened as file:// (yellow warning) → Double-clicking index.html will ALWAYS give NetworkError. Fix: GitHub Pages (https://<you>.github.io/<repo>/) OR locally: python3 -m http.server 8000 then http://localhost:8000 OR VS Code “Live Server”.
  • HTTP 403 from corsproxy.io → Expected. That service now needs an API key. Select proxy.cors.sh or Auto (which tries cors.sh first).
  • NetworkError / Failed to fetch on all proxies → Cloudflare is blocking the proxy. proxy.cors.sh is currently the only one that works for ebanglalibrary. Select it explicitly. If still blocked, wait 60s or deploy your own Cloudflare Worker (see README: worker code is 8 lines).
  • CORS error direct → Browser blocked direct request. Never use “direct” on GitHub Pages/file://.
  • Login required → Book gated. Chapters you tested are public, so this won’t happen.
  • Cover missing → CDN blocked image fetch — book still builds text-only.
